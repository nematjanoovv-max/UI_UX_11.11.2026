TUBDAN O'ZGARTIRILGAN VA OPTIMALLASHTIRILGAN 5 TA SOTA MACHINE LEARNING MODELI:
- Ma'lumotlar to'plami: UCI Machine Learning Repository (Cleveland Clinic, 302 bemor)

1. Ensemble Soft-Voting (SOTA Meta-Model):
   * ROC-AUC: 90.69% (Eng yuqori diskriminatsiya)
   * Recall (Sezuvchanlik): 96.97% (33 tadan 32 ta bemor aniqlandi)
   * F1-Score: 86.49%
   * Aniqlik (Accuracy): 83.61%
   * 5-Fold Stratified Kross-Validatsiya: 81.42% (±5.97%)

2. Gradient Boosting:
   * Aniqlik (Accuracy): 86.89% (Eng yuqori to'g'ri tashxis)
   * Recall (Sezuvchanlik): 96.97%
   * F1-Score: 88.89%
   * ROC-AUC: 87.99%
   * 5-Fold Stratified Kross-Validatsiya: 80.44% (±5.04%)

3. Support Vector Machine (SVM RBF):
   * Aniqlik (Accuracy): 83.61%
   * Recall (Sezuvchanlik): 93.94%
   * Specificity (O'ziga xoslik): 71.43%
   * F1-Score: 86.11%
   * ROC-AUC: 88.10%
   * 5-Fold Stratified Kross-Validatsiya: 81.09% (±6.09%)

4. Random Forest (100 Trees):
   * 5-Fold Stratified Kross-Validatsiya: 83.74% (Eng yuqori umumlashtirish)
   * ROC-AUC: 89.83%
   * Recall: 93.94%
   * Aniqlik: 80.33%

5. K-Nearest Neighbors (KNN, k=7):
   * Aniqlik (Accuracy): 81.97%
   * Recall: 90.91%
   * ROC-AUC: 88.20%
   * 5-Fold Stratified Kross-Validatsiya: 81.07% (±7.86%)
