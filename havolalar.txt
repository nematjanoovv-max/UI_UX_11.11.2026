CHUQUR VA KENG OPTIMALLASHTIRILGAN MACHINE LEARNING METRIKALARI:
- Ma'lumotlar to'plami: UCI Machine Learning Repository (Cleveland Clinic, 302 bemor)
- Support Vector Machine (SVM RBF):
  * Aniqlik (Accuracy): 83.61%
  * Recall (Sezuvchanlik): 93.94% (33 tadan 31 ta to'g'ri tashxis)
  * Specificity (O'ziga xoslik): 71.43%
  * F1-Score: 86.11%
  * ROC-AUC: 88.10%
  * 5-Fold Stratified Kross-Validatsiya: 81.09% (±6.09%)

- K-Nearest Neighbors (KNN, k=7):
  * Aniqlik (Accuracy): 81.97%
  * Recall (Sezuvchanlik): 90.91%
  * Specificity (O'ziga xoslik): 71.43%
  * F1-Score: 84.51%
  * ROC-AUC: 88.20%
  * 5-Fold Stratified Kross-Validatsiya: 81.07% (±7.86%)
